FIND THE ONE PIECE - VERSION CON BASE DE DATOS SQLITE

1. Coloca estos archivos en una carpeta de tu proyecto.
2. Activa tu entorno virtual (.venv).
3. Instala dependencias: python -m pip install -r requirements.txt
4. Inicia la interfaz: streamlit run app.py
   O ejecuta el menu: python main.py
5. Se crea automaticamente nodos.db en esta misma carpeta.
6. Para verlo en DBeaver: Nueva conexion > SQLite > selecciona nodos.db.
